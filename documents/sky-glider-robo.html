01담당 구현

메인 프로그래머로 플레이어 전체를 맡고, 기획자가 코드 수정 없이 데이터를 바로 반영할 수 있도록 데이터 파이프라인과 에디터 툴을 만들었습니다.

1.데이터 파이프라인 및 에디터 툴

  • JSON 데이터를 ScriptableObject로 자동 변환하는 에디터 툴 제작
  • 기획 데이터를 즉시 반영할 수 있는 구조 구축

결과데이터 반영 시간 단축 및 개발 속도 향상

2.플레이어 커스터마이징

  • 런타임 프리팹 교체 및 Animator 리바인딩 처리
  • 스킨 변경 시 장착 아이템의 Pivot 자동 동기화

결과캐릭터가 늘어나도 대응할 수 있는 확장 구조 확보

3.인벤토리 및 아이템 상태 관리

  • 단축키 기반 인벤토리 구조 설계
  • 아이템 내구도와 UI 동기화

결과실시간 상태 반영 시스템 안정화

4.업적 및 보상 시스템

  • ScriptableObject 기반 데이터베이스 구축
  • O(1) 탐색 구조 설계

결과시스템을 확장해도 성능 저하 없이 유지

5.플랫포머 기믹

  • 색상 판정, 이동 플랫폼, 소멸 발판 등 핵심 기믹 구현

결과게임 플레이 다양성 확보

02핵심 코드

아이템 데이터를 코드나 인스펙터에서 하나씩 입력하지 않고, 기획 JSON 한 파일에서 에셋과 데이터베이스까지 자동으로 만들어지도록 했습니다.

  • 기획 데이터 분리 — 아이템 수치를 JSON에서 관리해, 데이터가 바뀌어도 코드를 수정하지 않고 툴만 다시 실행
  • 에셋 이름 규칙 — Item_0001_영문명.asset처럼 ID를 4자리로 맞춰 프로젝트 창에서 ID 순으로 정렬되도록 함
  • DB 자동 연결 — 생성된 아이템 목록을 ItemDatabaseSO에 바로 등록해 수동 연결 누락을 방지
