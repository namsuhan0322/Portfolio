01담당 구현

팀의 유일한 프로그래머로 전체 코드를 맡아, 시스템 간 의존성을 줄이는 매니저 구조와 데이터 기반 콘텐츠 확장 구조를 설계했습니다.

1.Manager 패턴 기반 핵심 시스템

  • ScriptableObject 기반 데이터 구조 통합
  • 씬이 전환되어도 상태가 유지되는 중앙 관리 시스템 구축

결과시스템 간 의존성 감소 및 안정성 확보

2.낚시 미니게임 컨트롤 로직

  • 마우스 입력 기반 회전 연산(Atan2) 활용
  • 상태 기반으로 입력 충돌을 막는 구조 설계

결과직관적인 조작감 구현

3.Coroutine 기반 이벤트 제어

  • 여러 UI 이벤트가 동시에 실행되며 충돌하는 문제 방지
  • WaitUntil을 활용한 비동기 흐름 제어

결과안정적인 UX 제공

4.확률 기반 스폰 및 자동화 파이프라인

  • 가중치 기반 랜덤 시스템 설계
  • 잡은 물고기를 인벤토리와 도감에 자동 등록하는 구조 구현

결과데이터만 추가하면 콘텐츠를 확장할 수 있는 구조

02핵심 코드

물고기마다 등장 확률을 데이터(가중치)로 두고, 현재 씬에서 나올 수 있는 물고기 중 하나를 누적 가중치 방식으로 뽑습니다. 기획자가 확률 값만 바꿔도 등장 빈도가 조정됩니다.

  • 확률 합이 100이 아니어도 동작 — 총합 대비 비율로 뽑기 때문에, 기획자가 확률 합계를 맞추지 않아도 상대적인 등장 빈도가 유지됨
  • 잘못된 데이터 방어 — Mathf.Max(0, …)로 음수 확률이 입력되어도 계산이 깨지지 않도록 처리
  • fallback — 탐색이 끝까지 당첨되지 않는 예외 상황에서도 null 대신 마지막 후보를 반환
